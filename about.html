About ilikefish.space

Last updated: 2026-11-04

What this site is

ilikefish.space is a free browser game arcade. It collects small HTML5 games in one place so you can start playing without an account, a download, or a storefront. The site is an independent project run by fishesarethings.

Everything here is designed to work in a modern browser on desktop, tablet, or phone. Many games also work offline once the site has been loaded.

What you can do here

  • Play instantly: open the games library and pick a game.
  • Play offline: the site is a progressive web app, so supported pages stay available without a connection.
  • Keep your progress: game progress and preferences are stored locally in your browser, not in an account.
  • Make your own: use the Game Maker to assemble a small game package and export it.

How the catalogue is curated

Every game here is played before it gets a page. It has to start without instructions, work with the controls it advertises, and be finishable or loopable without a broken state. A prototype can sit in a folder for months, but it only joins the catalogue when it is actually playable from start to finish.

The catalogue is deliberately small. Eighteen games is enough to cover arcade, puzzle, idle, strategy and educational play without turning into an unfiltered portal. Each game page is written for that specific game: what it is, how the controls work, what to try first, and what the game does not do. If a game is unfinished or its page cannot be made accurate, it does not go in.

What you will not find here

  • No purchases or loot boxes. Nothing on the site costs money, and no game sells a currency, a booster or a random reward.
  • No account. There is nothing to sign up for, and no name, email address or phone number is requested to play.
  • No ads inside a game. Advertising stays outside the game frame, in one labelled unit per page, and disappears if no ad is returned.
  • No interstitials, pop-ups or auto-playing video. The site does not interrupt a session to show an ad.
  • No download promises. Games run in the browser; the only thing you can export is your own local progress.

How it works

Games are plain HTML, CSS, and JavaScript running in an iframe. There are no logins, purchases, or virtual currencies. Data such as settings and saved progress stays in your browser's local storage unless you clear it. Some games may load their own third-party libraries or services; see the Privacy Policy for details.

Who runs it

ilikefish.space is maintained by fishesarethings as a public project. The site's own code and text are released under the Unlicense. Games and bundled assets remain with their authors. It is hosted on GitHub Pages and delivered through Cloudflare.

How it is funded

The site is free to use. Advertising through Google AdSense helps cover the domain and hosting costs. You can control analytics and advertising choices in the cookie settings, and you can read more in the Privacy Policy.
