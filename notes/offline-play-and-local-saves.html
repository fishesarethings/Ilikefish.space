Offline play, local saves and what leaves your browser

Notes · 4 November 2026

Most of what happens on ilikefish.space happens in your browser. There is no account, no profile and no server-side save. That is good for privacy, but it means you should know where your progress actually lives.

What the service worker caches

The site is a progressive web app. On your first visit, a service worker stores the main pages, the game catalogue and the files needed by the games you open. On later visits those pages can load from the cache instead of the network.

That is why a game can keep working on a train with no signal. It is also why a stale page can appear after an update: the cache has to be refreshed. The site version in the footer and the refresh button exist for that reason.

Where progress lives

Game progress, settings and recommendation history are stored in your browser's local storage or IndexedDB. They are not sent to us. Clearing your browser data for the site removes them.

Some games keep a high score, some keep a whole save file, and some keep nothing at all. The game page usually says which. If a game matters to you, export a backup before clearing anything.

Export and import

The home page has an export button that writes your local storage and IndexedDB data to a JSON file, and an import button that reads it back. It is a blunt instrument, but it is enough to move progress between browsers or to keep a copy before a clean-up.

The optional online features

A few games offer optional online features such as leaderboards, cloud saves or multiplayer. Those features use Google Firebase. When you use one, the game creates an anonymous Firebase user ID and may store a display name you choose, scores, saves and room data. No email address, password or real name is required.

Those features are optional. A game only uses Firebase when you use one of them, and the game itself shows when it does. The Privacy Policy has the full detail.

What leaves your browser

  • Advertising and analytics: only after you consent, and only through the consent setup described on the privacy page.
  • Optional online game features: only when you use them, as above.
  • Normal web requests: the page and its files are requested from the host, as on any website.

Nothing else is sent. There is no account to delete because there is no account.
